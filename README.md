# Тарифный калькулятор

## Описание

Это конфигуратор тарифов мобильной связи, который позволяет пользователю выбирать параметры тарифа, такие как количество минут, СМС, интернет-трафика и дополнительные услуги, а затем видеть итоговую стоимость выбранного тарифа.

## Функциональные возможности

1. **Выбор минут** - диапазонный слайдер с несколькими ключевыми точками (100, 200, 300, 600).
2. **Выбор СМС** - диапазонный слайдер с несколькими ключевыми точками (0, 50, 100, 150).
3. **Выбор интернета** - диапазонный слайдер с несколькими ключевыми точками (5, 10, 15, 25).
4. **Дополнительные услуги** - чекбокс для аренды роутера.
5. **Итоговая стоимость** - пересчитывается автоматически при изменении любых параметров конфигуратора.
6. **Подтверждение данных** - по нажатию на кнопку формы выводится JSON объект с выбранными параметрами в `alert`.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <repo>
   ```
   
2. Перейдите в директорию проекта:
   ```bash
   cd <папка с проектом>
   ```

3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите проект:
   ```bash
   npm run dev
   ```
   
5. Откройте браузер по адресу: http://localhost:3000.
